# TravelMate AI

An intelligent AI-powered travel planning platform that helps users create personalized travel itineraries, manage budgets, explore destinations and plan journeys.

## Technology Stack

### Frontend
- React.js
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js
- REST APIs

### Database
- MongoDB Atlas
- Mongoose

### AI Integration
- Google Gemini API

### Maps and Weather
- Leaflet
- OpenStreetMap
- Open-Meteo
- OpenRouteService
